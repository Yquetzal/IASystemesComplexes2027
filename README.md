Le site lit les fichiers Markdown directement dans ce dépôt : les modifications apparaissent après rechargement de la page, sous réserve du cache de GitHub. Aucun transfert FTP n’est nécessaire pour modifier ces textes. Une copie locale est conservée dans le site et sert de secours si GitHub est indisponible. Ce dépôt ne déclenche aucun déploiement automatique. Les horaires et les paramètres du site restent dans `event.json`, dans le projet local ; les articles présentés sont lus dans Grist.
