Les textes peuvent être modifiés directement sur GitHub avec le bouton d’édition de chaque fichier.

Pour mettre à jour le site statique, recopier le contenu de `content/` dans son dossier `dist/content/`, puis transférer les fichiers du site sur le FTP. Ce dépôt ne déclenche aucun déploiement automatique. Les horaires et les paramètres du site restent dans `event.json`, dans le projet local ; les articles présentés sont lus dans Grist.
